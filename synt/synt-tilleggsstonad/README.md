Spring Boot-utgave av `synt_tilleggsstonad` fra [testnorge-syntetiseringspakker](https://github.com/navikt/testnorge-syntetiseringspakker/tree/master).

Tjenesten eksponerer API-endepunkter for syntetisk generering av tilleggsstonad-vedtak og bruker eksportert metadata fra legacy Python-modeller for Java-basert generering.
